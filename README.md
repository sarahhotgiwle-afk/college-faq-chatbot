# SSWCOE FAQ Chatbot – Campus Connect

A rule-based College FAQ Chatbot web application for Shree Siddheshwar Women's College of Engineering, Solapur.

> Student project — not an official college service. Confirm current details with the college.

## Features
- Interactive chatbot with quick-question buttons
- Keyword-based answers from a Python Flask back end
- Dark / light mode
- Responsive design for mobile and desktop
- About, Programs, FAQ and Contact sections

## Technologies
- **Front end:** HTML, CSS, JavaScript
- **Back end:** Python, Flask

## Project Structure
```
College_FAQ_Chatbot/
├── app.py
├── requirements.txt
├── README.md
└── templates/
    └── index.html
```

## How to Run
1. Install the requirements:
   ```
   pip install -r requirements.txt
   ```
2. Start the server:
   ```
   python app.py
   ```
3. Open `http://127.0.0.1:5050` in your browser.
